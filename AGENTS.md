# AGENTS.md — правила работы в репозитории

Курсовая МГТУ ИУ9 «Программная коррекция оптических искажений в микроскопии».
Домен, архитектура и текущее состояние — в `CONTEXT.md` (читать первым делом).

## Окружение и команды

- macOS, системный Python 3.9.6. Весь запуск — ТОЛЬКО через venv: `.venv/bin/python`.
  Прямой `python3` без venv = нет numpy/cv2, «ничего не работает».
- Зависимости: numpy, opencv-python-headless, Pillow, pytest. Новые — только с веской причиной.
- Тесты: `.venv/bin/python -m pytest tests/ -q` — должны быть все зелёные перед любым коммитом изменений.
- GUI: `.venv/bin/python app.py` (запускать из корня проекта — пишет `app.log` и PNG-артефакты в CWD).
- Git-репозитория пока нет; ничего не коммитить.

## Разработка: TDD

- Red → green: сначала падающий тест, потом минимальный код. Один цикл = один шов = один тест.
- Тесты только через публичные швы `achrom/` (список в CONTEXT.md), без моков внутренних функций.
- Ожидаемые значения в тестах — из независимой истины (известный k генератора, ручной расчёт),
  никогда не пересчитывать тем же способом, что реализация.
- Тест-инфраструктура — `achrom/synthetic.py` (генератор известной аберрации).

## GUI: потоки и Tk (главные грабли проекта)

- Tk не потокобезопасен: воркер НЕ трогает UI. Схема уже реализована в `app.py`:
  `_run_job` (воркер пишет результат в `self._pending`) + `_poll_pending` (главный поток
  забирает поллингом через `root.after`). Не возвращаться к `root.after` из потока —
  на системном Tcl/Tk macOS он молча умирает.
- `ImageTk.PhotoImage(..., master=self.root)` — master обязателен: без него ищется
  `_default_root`, которого на системном Tk macOS может не быть → RuntimeError.
- `messagebox` на уничтоженном root открывает невидимый модальный диалог и вешает процесс —
  перед показом проверять `self._root_alive()`.
- Результат обработки всегда пишется в PNG-файлы ДО показа в UI: закрытие окна
  во время обработки не должно терять результат.
- Все кнопки обёрнуты `@log_errors`: трейсбек в `app.log` + messagebox. KeyboardInterrupt —
  INFO «прервано пользователем», не ERROR.

## Логирование

- `app.log` — единственный источник правды при разборе инцидентов у пользователя.
  При изменении пайплайна добавлять тайминги стадий (образец: `_blind_job`,
  логи «итерация N: … за Xс»).
- Пользователь приносит лог — читать его целиком, хронологию сверять с его словами.

## Известные ловушки macOS

- Системный Tcl/Tk deprecated: `TK_SILENCE_DEPRECATION=1` ставится до импорта tkinter.
- App Nap: перекрытое окно → macOS троттлит процесс, 4с превращаются в 50с.
  Если тайминги в логе взлетели — спросить, было ли окно перекрыто.
- `screencapture` из терминала без прав не работает — скриншоты для проверки GUI не путь.

## Артефакты

- `result_*.png`, `demo_*.png` — выходы GUI (до/после/зум), `app.log` — журнал,
  `data/` — тестовые изображения (см. CONTEXT.md). Это генерируемые файлы.
