# Коррекция хроматических аберраций

Убирает поперечную (латеральную) хроматическую аберрацию — цветные ореолы по краям кадра — и остаточные цветные каёмки у контрастных границ. Опционально компенсирует продольную (аксиальную) аберрацию: восстанавливает резкость расфокусированных каналов деконволюцией Ричардсона–Люси. Работает в двух режимах: по калибровочному кадру точечной мишени и «слепой» — по самому снимку, без калибровки.

## Что нужно

Python 3.9+ и пакеты: numpy, opencv-python-headless, Pillow, pytest.

## Установка

```sh
python3 -m venv .venv
.venv/bin/pip install numpy opencv-python-headless Pillow pytest
```

## Запуск

```sh
.venv/bin/python app.py
```

В окне: «Загрузить снимок» → выбрать файл → дождаться обработки. Исправленное изображение пишется в `results/<имя>.png`. Флажок «Мягкое удаление остаточных цветных ореолов» включает вторую стадию (подавление каймы), «Компенсация продольной аберрации» — третью (выключена по умолчанию). Журнал — `app.log`.

Пакетная обработка из командной строки — файлы или каталоги:

```sh
.venv/bin/python app.py data/lens_ca.jpg data/
.venv/bin/python app.py --axial data/blur.png
.venv/bin/python app.py --axial-cal мишень.png data/
```

`--axial` включает компенсацию продольной аберрации, `--axial-cal <мишень>` — калибровку ядер по кадру точечной мишени (измеренные σ логируются в консоль).

## Тесты

```sh
.venv/bin/python -m pytest tests/ -q
```

Ожидается `60 passed`.
